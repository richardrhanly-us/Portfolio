The site highlights selected projects in backend development, data applications, systems programming, automation, and full-stack development.

## Running Locally

```bash
git clone https://github.com/richardrhanly-us/Portfolio.git
cd Portfolio
npm install
npm run dev
```

## Production Build

```bash
npm run build
```
